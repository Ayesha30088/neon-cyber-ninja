# Neon Cyber-Ninja Slice

A professional, production-ready Fruit Ninja style arcade game built using pure vanilla HTML5, CSS3, and modern JavaScript with modular classes (`CyberNinjaGame`).

## Project Structure

  • index.html (Unified markup, Tailwind styles, and modular JS class)
  • Assets (Procedurally generated shapes, neon particle trails, Web Audio synth)

## Core Features

• Web Audio API synthesizer for retro sound effects & background chord progression.
• Dynamic canvas physics with arc trajectories and slice splitting mechanics.
• LocalStorage high scores and leaderboard tracking.
